## Resumen
Se analizaron 6 finales (2023-2024). Cada final tiene 10-12 ejercicios que cubren TODA la materia.
Para el **final de equivalencia** solo importan los ejercicios mapeados a los 5 subtemas.

**NOTA:** Estos son finales normales (cubren toda la materia). El final de equivalencia solo evalua los 5 subtemas aislados, pero estos finales sirven para practicar el tipo de preguntas.
