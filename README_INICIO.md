### 🔶 Tema 3: Algebras de Boole (48 KB)

**Qué aprenderás:** Identificar algebras de Boole, calcular átomos, verificar distributividad.

**Conceptos clave:**
- Red (lattice)
- Distributiva
- Complementada
- Divisores de n (D_n)
- Criterio: D_n es Boole ⟺ n libre de cuadrados

**Ejercicios clave:** 26a-e, 27, 28, 9-13

**Duración recomendada:** 2-3 semanas (4-5 ejercicios/semana)

---

### 🔴 Tema 4: Congruencias (39 KB)

**Qué aprenderás:** Calcular restos grandes, resolver ecuaciones congruenciales, φ de Euler.

**Conceptos clave:**
- Teorema de Fermat: a^(p-1) ≡ 1 (mod p)
- Teorema de Euler-Fermat: a^φ(n) ≡ 1 (mod n)
- Ecuaciones ax ≡ b (mod n)
- φ(n) = n·∏(1-1/p) para p|n

**Ejercicios clave:** 18a-e, 19a-c, 21a-f, 14, 15, 16

**Duración recomendada:** 1.5-2 semanas (4-5 ejercicios/semana)

---

### 🟣 Tema 5: Recurrencias (39 KB)

**Conceptos clave:**
- Ecuación característica
- Solución homogénea
- Solución particular (por método de coeficientes indeterminados)
- Resonancia
- Inducción

**Ejercicios clave:** 8a-c, 4, 7a-c, 10, 11a-d

## 🔑 Formulas a Memorizar

### Tema 1: Reglas de inferencia
```
P.U.: ∀x:P(x) → P(a)
P.E.: ∃x:P(x) → P(a) [con "a" arbitrario]
M.P.: P→Q, P ⊢ Q
M.T.: P→Q, ¬Q ⊢ ¬P
S.D.: P∨Q, ¬P ⊢ Q
De Morgan: ¬(P∨Q) ≡ ¬P∧¬Q
```

### Tema 2: Equivalencia
```
Reflexiva: aRa
Simétrica: aRb → bRa
Transitiva: aRb, bRc → aRc
Cl(a) = {x : aRx}
A/R = {Cl(a) : a ∈ A}
```

### Tema 3: Boole
```
D_n es Boole ⟺ n = p₁·p₂·...·pₖ (libre de cuadrados)
|D_n| = 2^k (si n tiene k factores primos)
Átomos de D_n = primos que dividen n
```

### Tema 4: Congruencias
```
Fermat: p primo, mcd(a,p)=1 ⟹ a^(p-1) ≡ 1 (mod p)
Euler-Fermat: mcd(a,n)=1 ⟹ a^φ(n) ≡ 1 (mod n)
φ(n) = n·∏(1-1/p) para p primo | n
ax ≡ b (mod n) tiene solución ⟺ mcd(a,n)|b
Número de soluciones = mcd(a,n)
```

### Tema 5: Recurrencias
```
Homogénea orden 2: a_n = c₁·r₁^n + c₂·r₂^n [r₁, r₂ raíces]
No-homogénea: a_n = a_n^(h) + a_n^(p)
Inducción: Caso base + Paso inductivo
```
